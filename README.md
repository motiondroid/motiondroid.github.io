# MotionDroid — Video Editor Portfolio

Live site: https://motiondroid.github.io

## Files

Saari files ek hi jagah (root) par hain — koi folder nahi, isliye upload karna aasaan hai.

| File | Kaam |
|---|---|
| `index.html` | Poori website ka structure aur text (naam, services, prices, contact) |
| `style.css` | Design, colors aur saari animations |
| `script.js` | Scroll animation, timeline, counters, showreel player |
| `portrait.webp` | Hero section wali photo (transparent background) |
| `logo-mark.png` | Nav bar ka MD logo |
| `logo-full.png` | About section ka poora logo |
| `favicon.png` | Browser tab ka icon |
| `showreel.mp4` | Showreel video |
| `showreel-thumbnail.jpg` | Showreel ka thumbnail |
| `work-*.mp4` | Recent work ke 4 videos |
| `thumb-*.jpg` | Recent work cards ke thumbnails |
| `.nojekyll` | GitHub ko files ko bina badle serve karne deta hai (delete mat karna) |

## Kuch badalna ho to

| Kya badalna hai | Kahan |
|---|---|
| Text, prices, email, phone, links | `index.html` (GitHub par file kholo → ✏️ pencil icon → edit → Commit) |
| Colors | `style.css` → sabse upar `:root { --accent: #FF6A3D; ... }` |
| Recent work ka title/description | `index.html` mein `id="work"` section |
| Photo / video / thumbnail | Nayi file **same naam** se upload karo — purani apne-aap replace ho jaayegi |

## Rules

- File ke naam mat badlo (capital/small letters bhi same rehne chahiye — `Style.css` ≠ `style.css`).
- Koi file kisi folder ke andar mat daalo — sab `index.html` ke saath root mein rahein.
- GitHub par ek file 25 MB (web upload) se badi nahi honi chahiye — video compress karke daalo.
